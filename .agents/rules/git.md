# Git Identity Rules

- **Respect Global Git Identity**: Always allow Git to use the user's global identity (`Omega131 <devidasbamane9@gmail.com>`).
- **No Local Email Overrides**: Never execute repository-level `git config user.email` or `git config user.name` with synthetic, dummy, or noreply addresses (e.g., `@users.noreply.github.com`, `@example.com`).
- **Commit Attribution**: Ensure all commits retain the user's verified GitHub email so that contributions are attributed to their GitHub profile (`Omega131`).
